สร้าง Dashboard แสดงข้อมูลรายงาน Executive Report โดยใช้ HTML, CSS, JavaScript และ Three.js
เขียน Claude.md การอ่านค่ารายงาน จะต้องอ่านจาก Link Sheet Online ที่อยู่ในไฟล์ "แบบฟอร์มรายงาน Kambis.txt" ในนั้นจะมีลิ้งค์รายงานอยู่หลายอัน และทุกครั้งที่ Dashboard มีการอัพเดทข้อมูลจะต้องมี Data Analysis ตรวจและวิเคราะห์ข้อมูลความถูกต้องทุกครั้ง

ก่อนเริ่มสร้าง Dashboard ให้สร้างผู้ทำงานกับข้อมูลก่อน ดังนี้
ขั้นที่ 1 สร้าง Agent สำหรับเป็นผู้เชี่ยวชาญในการอ่านและวิเคราะห์ข้อมูล Data Analysis
ขั้นที่ 2 สร้าง Agent สำหรับเป็นผู้เชี่ยวชาญในการ ออกแบบ UX/UI(Front-end) ทำงานร่วมกับ Data Analysis ในการออกแบบ Dashboard
ขั้นที่ 3 สร้าง Agent สำหรับเป็นผู้เชี่ยวชาญในการ ออกแบบ back-end Dev ในการออกแบบโครงสร้างเว็บไซต์ Dashboard ให้ทำงานได้เสถียรและแสดงข้อมูลได้ถูกต้อง

Requirements:
- แสดงโปรเจกต์เป็นการ์ดกระจกแบบ Glassmorphism
- มีรายงานแยกตามส่วนของข้อมูลชัดเจน
- สามารถกดเพื่อดูรายละเอียดเพิ่มเติมได้
- มี Filter, Sorting, Searching ของแต่ละข้อมูล
- รองรับ Responsive ทั้ง Desktop และ Mobile
- มี Loading Screen เวลากำลังโหลดข้อมูลเพิ่อมาแสดงผล
- ใช้ Vanilla JavaScript ไม่ใช้ Framework
